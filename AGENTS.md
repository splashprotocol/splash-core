# Agent handoff

For royalty pool mainnet deployment work, read [docs/deployment/mainnet-royalty-handoff.md](docs/deployment/mainnet-royalty-handoff.md) and the exact [mainnet script list](docs/deployment/mainnet-royalty-script-list.md) before exporting or publishing scripts. They record deployment tooling, artifact provenance, the intended 13-script publication set, and remaining validation work.

Do not treat archived CBOR or Preprod DAO artifacts as the current mainnet release. Verify the source revision, script hashes, and DAO public-key parameters for every new export.
